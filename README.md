# pizza-sales-analytics-powerbi-dashboard
Interactive Pizza Sales Analytics Dashboard built with Power BI to analyze revenue, orders, pizza sales, product performance, and customer ordering patterns.
Pizza Sales Analytics Dashboard – Power BI

🍕 📌 Project Overview

This project is an interactive Pizza Sales Analytics Dashboard developed using Microsoft Power BI. The dashboard provides a comprehensive view of pizza sales performance and helps identify important trends, customer ordering patterns, and best-selling products.

The goal of this project is to transform raw sales data into clear, interactive, and business-oriented insights.

| 📈 Average Order Value      |   23.53 |
| 🍕 Average Pizzas per Order |    1.13 |
📈 Dashboard Features
Monthly Revenue Trend – Analyze revenue performance throughout the year.
Revenue by Pizza Size – Compare sales across different pizza sizes.
Top 10 Best-Selling Pizzas – Identify the pizzas generating the highest revenue.
Revenue by Pizza Category – Analyze performance across pizza categories.
Orders by Day – Understand which days generate the most orders.
Interactive Filters/Slicers – Filter the dashboard by pizza category, pizza size, and month/year.

🔍 Key Insights
Total revenue generated was approximately 102.34K.
Around 4K orders were placed, resulting in approximately 5K pizzas sold.
Friday recorded the highest number of orders among the days shown.
Large-size pizzas contributed the highest revenue.
Chicken-category pizzas dominated the displayed category revenue.
The Thai Chicken Pizza was the top-selling pizza among the displayed top performers.
🎯 Project Objective

The primary objective of this project was to develop a dashboard that enables users to:

Monitor overall sales performance.
Identify high-performing pizza products.
Understand customer ordering patterns.
Analyze revenue trends.
Support data-driven business decisions.
